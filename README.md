# Agentopia

Agentopia is a story-driven interactive presentation for a social catalyst that helps friends reconnect through a shared world for their personal Agents.

## Run locally

Open `index.html` in a browser. The six-page story presentation includes English and Chinese copy, page-turn navigation, a Daily Report interaction, and a simulated group-chat reply. `product.html` opens the fuller product dashboard demo.

The chat is a local prototype interaction. It does not send messages to external apps.

## GitHub Pages

The `main` branch is configured to deploy this static site with GitHub Actions.
